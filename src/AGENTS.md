# Uncodixfy Rules

## Core Principle
This project must NOT look like an AI-generated UI.

## Forbidden Patterns
- generic SaaS layout (hero + cards + footer)
- excessive rounded corners
- glassmorphism / random gradients
- floating cards everywhere
- template-like sections

## Design Requirements
- every section must have a clear purpose
- prioritize real product UX over decoration
- mobile-first layout is mandatory
- avoid demo-like UI

## Interaction Rules
- every clickable element must have feedback
- spacing and typography must be consistent
- no cluttered UI

## If UI looks generic
→ redesign it completely until it feels like a real product

## Weilife Product Context

This is NOT a generic web app.

This is:
- a climate + personality quiz experience
- interactive, emotional, and engaging
- similar to a "psychology test" or "Spotify Wrapped"

## UX Requirements

- The experience must feel like a guided journey, not a form
- One screen = one main action
- Avoid overwhelming the user with too much content at once
- Prioritize clarity and readability on mobile devices

## Mobile-First Rules (Critical)

- Design for 360px–430px width first
- All interactions must be thumb-friendly
- Text must be easy to scan (short paragraphs, clear hierarchy)
- Avoid dense layouts and clutter

## Component-Level Expectations

- QuizSection must feel like interactive choices, not inputs
- ResultDashboard must feel like a shareable result card
- StorySegment must feel like a readable narrative, not raw text

## If UI still feels like demo

→ Simplify it
→ Reduce elements
→ Focus on one clear user action per screen
